# Khmer Book Cover Studio

Printable (1:1, mm-accurate) book covers for Khmer primary school books: front, spine and back, for any page count.

- Grades 1–6, 13 subjects, Khmer-style scenes or your own Gemini / uploaded pictures
- Editable name / grade / ID / teacher / school-year box, resizable
- Subject learning charts on the back cover
- Everything is saved in your browser; the Gemini API key never leaves it except to call Google

Open `index.html` (or the GitHub Pages site) and print at **Scale 100%**, margins **None**.
