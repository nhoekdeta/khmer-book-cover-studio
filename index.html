Print

Each page is the exact cover size in mm, ready for a print shop. Needs internet the first time (fonts and PDF library).
📋 Print for a whole class (name list)
Format: name, ID, class section, teacher (only the name is required). You can paste straight from Excel or Google Sheets. A blank class or teacher uses the value in the Text section.
In the print dialog choose Scale: 100% / Actual size, margins None, and turn Headers & footers off. The page size is set automatically to match the cover.
